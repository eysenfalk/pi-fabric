# Implement the approved change

- Re-read applicable local instructions and confirm the existing seam before editing.
- Fix the demonstrated root cause with the smallest coherent change.
- Preserve unrelated work and avoid speculative cleanup or future-proof abstractions.
- Keep responsibilities local, names explicit, and code readable to contributors who did not author it.
- Add or adjust evidence at the public behavior boundary, not only internal implementation details.
- If repository truth materially invalidates the approved workflow, stop before that expansion and report the needed workflow change.
- Do not commit, publish, deploy, mutate production, or cross another consequential boundary without explicit authority.
